Configuration
=============

No specific configuration required beyond base_archive_clean module configuration.

Usage
=====

This module extends the base_archive_clean framework to support archiving of mail.message records.

Features:

* Archive state tracking for mail messages (active/archived/restored)
* Archive eligibility computation based on configurable rules
* Automatic archiving jobs for old messages
* Attachment reference preservation during archiving
