**Manual Archiving**

1. Go to Archive → Archive Jobs
2. Click "Create" and select:
   - Archive Rule to apply
   - Optional: Manual record selection
3. Click "Preview" to see what will be archived
4. Click "Start Archive Job"
5. Monitor progress in job list

**Finding Duplicates**

1. Go to Archive → Find Duplicates
2. Select scope (all attachments or specific models)
3. Click "Analyze"
4. Review duplicate groups
5. Select groups to merge
6. Click "Merge Selected" (keeps newest, archives duplicates)

**Searching Archived Data**

1. Go to Archive → Search Archived
2. Enter search criteria:
   - Keywords
   - Model
   - Date range
3. Results show both local and archived records
4. Archived records show cloud icon ☁️ and backend name

**Restoring Data**

Method 1 - From Search:
1. Search for archived record
2. Click on record
3. Click "Restore to Odoo"

Method 2 - Bulk Restore:
1. Go to Archive → Restore Wizard
2. Select records by:
   - Archive batch ID
   - Date range
   - Model/IDs
3. Click "Restore Selected"

**Monitoring**

View statistics and health:
- Archive → Dashboard: Overall stats
- Archive → Jobs: Job history and status
- Archive → Backends: Storage usage per backend

**Deduplication Workflow**

1. Navigate to Attachments
2. New "Duplicate Of" field shows if file is a duplicate
3. "Duplicate Count" shows how many copies exist
4. Grouped view shows all duplicates together
5. Manual merge: Right-click → "Merge Duplicates"
